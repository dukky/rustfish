# CLAUDE.md

Start here, in this order:

1. `docs/standing-rules.md`: how to work (owner's rules; apply on every machine).
2. `plan.md`: where the project is, what is running, what to do next.
3. `AGENTS.md` (imported below): commands, layout, testing.
4. `docs/development.md`: the merge queue and SPRT process.

Machine-specific details (how to reach other machines, local paths, quirks)
live in a gitignored `CLAUDE.local.md` on each machine, never in this public
repository.
