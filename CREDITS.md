# Credits and attribution

rustfish is an independent engine. Its code was written for this project; no source code was copied from
other chess engines. Other engines are used only as opponents in tests (see "Testing" below). The ideas it
builds on are the shared, published knowledge of computer chess; the ones it relies on most are credited
here. If you believe something is missing or wrong, please open an issue.

## Ideas and published methods

- **Alpha-beta search and its standard refinements** (principal variation search, transposition tables,
  null-move pruning, late move reductions, futility pruning, singular extensions, ProbCut, killer and
  history heuristics, static exchange evaluation, quiescence search): decades of published computer-chess
  research, much of it collected on the [Chess Programming Wiki](https://www.chessprogramming.org/).
- **NNUE** (efficiently updatable neural network evaluation): Yu Nasu, 2018. Our network shapes, trainers
  (`tools/nnue-trainer*`) and all training data are our own (see `docs/nnue.md`).
- **Upcoming-repetition (cycle) detection with cuckoo tables**: Marcel van Kervinck's published method.
  `src/cycle.rs` is a clean-room implementation from the published description (see its header).
- **Syzygy endgame tablebases**: format and tables by Ronald de Man. `src/syzygy.rs` is a clean-room
  prober written from public prose descriptions and experiments, not from any existing prober's code;
  how each detail was established is in `docs/syzygy-format.md`. The tablebase files themselves are not
  part of this repository.
- **SPRT and SPSA**: the sequential probability ratio test (Abraham Wald) with the pentanomial game-pair
  model popularised by distributed engine testing, and simultaneous perturbation stochastic approximation
  (James Spall) for parameter tuning; our implementations are in `scripts/` and `.github/workflows/`.

## Training data

All NNUE training data is generated by rustfish's own self-play (`src/datagen.rs`). No external games,
positions or evaluations are used for training.

## Testing (used, not distributed)

- [fastchess](https://github.com/Disservin/fastchess) runs the games in our GitHub Actions tests.
- Opening positions for tests: `UHO_Lichess_4852_v1` from
  [official-stockfish/books](https://github.com/official-stockfish/books), downloaded at test time.
- Rating anchors: the engines listed in `scripts/anchors-elite.json` and `scripts/anchors.json`, built from
  their own repositories at test time, with ratings from the [CCRL](https://computerchess.org.uk/ccrl/)
  Blitz list. Thanks to their authors and to the CCRL testers.
- The [Lichess tablebase API](https://tablebase.lichess.ovh/) served as an oracle when validating our
  Syzygy prober.

## Deployment

The Lichess bot (`deploy/lichess-bot/`) runs rustfish behind
[lichess-bot](https://github.com/lichess-bot-devs/lichess-bot), which is downloaded when the image is
built and is under its own licence; it is not part of this repository.
