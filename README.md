# rustfish

A chess engine in Rust with no dependencies beyond the standard library.
Stockfish 17 at skill level 17 (the original goal) is passed; the targets are
now places on the CCRL Blitz list (single-CPU engines, best versions; numbers in
`scripts/ccrl-targets.json`):

| Mid term: top 100 | 3506 | reached 2026-11-13 (3562), now ~100 Elo clear |
| Next | 3700 | ~90 Elo to go |
| Long term: top 10 | 3751 | #10 |

rustfish measures **3613** (CCRL ladder 2026-11-22, CI 3599–3627, 440 games at
120+1 against 11 CCRL-rated anchors from 3487 to 3773, main `e8a3495`: gen 11
pairwise-head net plus the 21–22 Nov search merges). Ladders before
2026-11-21 19:00 used an anchor set mostly below rustfish and read high (the
3640 of 2026-11-21 is ~3600 on the bracketing set); compare only ladders on the
current set. History in `tests/ladder-log.jsonl`.

**Live progress dashboard: https://rustfish-dash.dev.duk.im**: current strength,
the test in flight, the merge queue, recent results, strength over time and the
roadmap. It reads everything live from this repository (`tests/*.jsonl`, the
`queue-state` branch, `plan.md`, `scripts/queue-settings.json`) and GitHub
Actions, so it never needs updating by hand; redeploy only when
`deploy/dashboard/` itself changes (see its README).
